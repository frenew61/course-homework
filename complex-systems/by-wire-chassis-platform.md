# 复杂系统工程层级拆解：面向高级别自动驾驶的线控底盘平台

> 课程：Complex Systems Engineering（复杂系统工程）
> 所选系统：**面向高级别自动驾驶的线控底盘平台**
> 定位层级：**系统（Systems）层**
> 层级主线：任务 Mission → 体系 SoS → 整机 Vehicles → **系统 Systems** → 子系统 Sub-systems → 模块 Modules

---

## 一、所选系统与层级定位

### 1.1 系统定义

面向 L4/L5 高级别自动驾驶的线控底盘平台，是一套以电信号为指令载体、通过冗余架构实现制动、转向、驱动、悬架等运动控制功能的整车运动执行平台。它向上承接自动驾驶系统（智驾域）的规划决策指令，向下驱动各执行部件，是连接「大脑决策」与「车轮执行」的关键环节。

### 1.2 为什么落在「系统（Systems）层」

- 它本身由多个可独立设计、独立验证的**子系统**（线控制动、线控转向、线控驱动、主动悬架、底盘域控）集成而成；
- 它不能单独完成载客物流任务，必须装到**整车（整机）**上、并入**自动驾驶出行体系**才能发挥价值；
- 它在整车拓扑中与动力、车身、智驾、座舱等系统并列，是整车下的一个「系统」；
- 其内部各执行器、控制器、传感器等是更底层的**子系统 / 模块**，不属于本层定义。

> 结论：在「任务—体系—整机—系统—子系统—模块」的层级中，线控底盘平台处于**系统（Systems）层**，上承整机与体系，下接子系统与模块。

## 二、各层级要素补全（上、中、下）

### 2.1 任务层 Mission（最上层：为什么做、达成什么目标）

任务是系统存在的最终目的，回答「要解决什么出行问题、达成什么使命」。

| 序号 | 任务要素 | 说明 |
|---|---|---|
| M1 | 安全出行与交通运输 | 在城市/高速/园区等场景下，安全、可靠地完成人员运输与货物配送 |
| M2 | 高级别自动驾驶落地 | 支撑 L4/L5 自动驾驶车辆在无人工接管条件下连续、稳定运行 |
| M3 | 全域运动操控 | 按智驾决策精确完成加减速、转向、制动、平顺性调节等运动响应 |
| M4 | 功能安全与失效兜底 | 任一执行链路失效时仍能降级行驶或安全停车，保障乘员与道路安全 |
| M5 | 节能与舒适体验 | 在保证操控的同时降低能耗、提升乘坐平顺性与乘坐品质 |

### 2.2 体系层 SoS（System of Systems：由多类系统组成的大系统）

体系是为完成同一任务而协同的多个系统（整车 + 交通 + 信息基础设施）的集合，线控底盘平台是其中之一。

| 序号 | 体系要素 | 说明 |
|---|---|---|
| S1 | 自动驾驶整车系统族 | 乘用车、Robotaxi、干线物流卡车、无人配送车等多车型共享同一底盘平台 |
| S2 | 感知—决策—规划系统 | 摄像头、雷达、高精地图、定位与算法域控，向底盘下发运动指令 |
| S3 | 动力与能源系统 | 三电系统（电池、电机、电控）、能量管理与热管理，提供驱动力与能源支撑 |
| S4 | 车身与座舱系统 | 车身结构、乘员舱、人机交互、安全带/气囊等被动安全系统 |
| S5 | 车路云协同系统 | V2X 路侧单元、云端调度与监控、OTA 升级与远程诊断平台 |
| S6 | 交通与基础设施体系 | 智能道路、信号控制系统、停车与充电网络等外部环境要素 |

### 2.3 整机层 Vehicles（搭载本系统的整车）

整机即具体车型/车辆，线控底盘平台安装并服务于其上。

| 序号 | 整机要素 | 说明 |
|---|---|---|
| V1 | 自动驾驶乘用车 | 家用/出行乘用车型，城市道路与高速场景 |
| V2 | Robotaxi 无人出租车 | 无人驾驶运营车辆，对底盘冗余与可靠性要求最高 |
| V3 | 自动驾驶物流车/卡车 | 干线物流、园区配送等货运车型，承载大载荷与长续航需求 |
| V4 | 底盘整车集成要素 | 轴距/轮距、整车质量、轴荷分配、离地间隙、安装接口与布置空间 |

### 2.4 系统层 Systems（本层：面向高级别自动驾驶的线控底盘平台）

本层为分析主体，由下列核心系统能力域构成一个完整的线控底盘平台。

| 序号 | 系统要素 | 说明 |
|---|---|---|
| SY1 | 线控制动系统 | 电子液压/电子机械制动（EHB/EMB），实现电信号制动与冗余制动 |
| SY2 | 线控转向系统 | 转向执行与路感反馈解耦，支持自动转向与转向冗余备份 |
| SY3 | 线控驱动/扭矩控制 | 驱动扭矩分配、牵引力控制与纵向运动执行 |
| SY4 | 主动悬架与车身姿态控制 | 减振、侧倾/俯仰抑制、高度与刚度调节，支撑平顺性 |
| SY5 | 底盘域控制系统（底盘 ECU/域控） | 整合各子系统控制策略、冗余管理、与智驾域通信的中央控制器 |
| SY6 | 底盘冗余与功能安全架构 | 双路供电、双路通信、双执行通道与失效降级策略（ISO 26262） |

## 三、串联阐述：任务—体系—整机—系统—子系统—模块

在高级别自动驾驶出行这一**任务（Mission）**牵引下，由感知决策、动力能源、车身座舱、车路云协同等多个系统共同构成**体系（SoS）**；这一体系最终落地到具体的自动驾驶乘用车、Robotaxi、物流卡车等**整机（Vehicles）**上。

在每台整车内部，面向高级别自动驾驶的**线控底盘平台（Systems，本层）**作为整车运动执行的核心系统，向上接收智驾域下达的加速、减速、转向、平顺性调节指令，向下组织线控制动、线控转向、线控驱动、主动悬架与底盘域控等**子系统（Sub-systems）**协同工作；各子系统进一步分解为传感器、执行电机、阀组、电路板、通信芯片、控制算法等**模块（Modules）**，完成最底层的信号采集、功率驱动与策略执行。

整条链路自顶向下为：

> **出行任务（为什么跑）→ 自动驾驶体系（和谁一起跑）→ 整车（装在哪台车上跑）→ 线控底盘平台（怎么执行运动）→ 各底盘子系统（由哪些功能单元执行）→ 硬件/软件模块（靠哪些元器件与算法落地）**

而自底向上则是：模块采集信号、输出力矩与动作，子系统完成功能闭环，系统实现整车运动控制，最终支撑整机融入体系、完成既定出行任务。

## 四、层级关系一览表

| 层级 | 英文 | 本案例对应要素 | 与所选系统的关系 |
|---|---|---|---|
| 任务 | Mission | 安全出行、高级别自动驾驶落地、全域操控、失效兜底、节能舒适 | 上层目的 |
| 体系 | SoS | 整车族、感知决策、动力能源、车身座舱、车路云、交通设施 | 上层大系统环境 |
| 整机 | Vehicles | 自动驾驶乘用车、Robotaxi、物流卡车及整车集成参数 | 搭载本系统的载体 |
| **系统** | **Systems** | **面向高级别自动驾驶的线控底盘平台** | **分析主体（本层）** |
| 子系统 | Sub-systems | 制动、转向、驱动、悬架、域控、冗余安全等子系统 | 向下分解单元 |
| 模块 | Modules | 传感器、电机、阀组、电路板、通信芯片、算法模块等 | 最底层硬件/软件单元 |
